# Story projects

Use `studio init "Title" --preset default` after the title is supplied or naming delegated. Add a source file and selected style snapshots when needed. The original is preserved and hashed; scaffolding grants no permission.

Every new project is initialized on `story/<safe-title-slug>` from the studio base. A clone-and-paste request triggers this routine setup automatically through the agent. The branch/base/source record is `production/git.json`; keep story work on that branch and use `studio resume stories/<safe-title-slug>` for a committed existing story. Unrelated edits and existing branches are preserved. See [branch workflow](../docs/15-story-branches.md).

New projects default to Fast configuration → actual authorization → continuous agent work → complete preview decision → master/QA/export. Story-only work skips film production. Presets reuse preferences and exact treatment snapshots, never another story's canon or authorization. Existing projects without a workflow record remain Strict. See root `docs/13-fast-workflow.md`.

Keep all story-specific knowledge and real media evidence inside its project. One video uses part_001; Fast multipart work details selected parts progressively against whole-story dependencies. Preserve immutable deliveries and actual inspection records.
